## 8. Failure modes worth not rediscovering

- ✅ `gh release delete <tag>` and `GET /releases/tags/<tag>` do not work on drafts. Address
  drafts by numeric release ID, or list and filter on `tag_name`.
- ✅ Job and step `conclusion` are useless as probe signals when steps swallow exit codes. Run
  `37202029536` reported every job `success` while being entirely signal-free.
- ✅ `gh run list --limit 1` immediately after a push returns the *previous* run. Filter on a
  changed run id before trusting `status: completed`.
- ⚠️ `pixi run backlog -- …` is the documented route for Backlog CLI work, but Pixi is not
  installed in the agent sandbox. The equivalent used here is
  `npx -y backlog.md@1.53.0 …` — the exact version pinned in `package.json`.
- ✅ `backlog decision` has **no `update` subcommand**, only `create` and `list`. Decision
  bodies are authored in the file after CLI creation.
