# Backlog.md data directory

This directory is the canonical delivery and normative-project-knowledge system for `pixi-release`. Use `pixi run backlog -- …` to create and update tasks, milestones, project documents, and decisions. Do not edit task Markdown directly.

The initial scaffold intentionally contains configuration only. Create the first milestones, decision records, and implementation tasks through the Backlog.md CLI after `pixi run setup`; this preserves Backlog's IDs, metadata, links, plans, acceptance criteria, dependencies, and board indexes.
