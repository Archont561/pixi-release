## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
doc-3 §2.2 determines that relock.yml and publish-sandbox.yml are consumer-generated by pixi-sandbox and adopted as-is, and that .pixi-sandbox.toml is what they read. This task applies that determination to this repository: the pack publishes the default development environment onto the orphan branch sandbox/developer-linux-64, so a release artifact and a fresh clone can restore the same tools. decision-10 §3 keeps the two tools disjoint — pixi-sandbox owns these two files, pixi-release owns release.yml and auto-release.yml. The files are adopted verbatim at pixi-sandbox 0.8.0 (starter commit 5710a5d); they are generated, so they are never hand-edited. Regenerating them requires `pixi sandbox init`, which needs the conda-forge channel this sandbox cannot reach.
