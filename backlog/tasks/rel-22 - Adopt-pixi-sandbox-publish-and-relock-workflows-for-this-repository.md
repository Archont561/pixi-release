## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
doc-3 §2.2 determines that relock.yml and publish-sandbox.yml are consumer-generated by pixi-sandbox and adopted as-is, and that pixi-sandbox.toml is what they read. Applied to this repository: the pack publishes the default development environment onto the orphan branch sandbox/developer-linux-64, so the pinned toolchain is restorable from a git clone alone. decision-10 §3 keeps the two tools disjoint — pixi-sandbox owns these two files, pixi-release owns release.yml and auto-release.yml. The workflows are verbatim at pixi-sandbox 0.8.0 (starter commit 5710a5d) and are never hand-edited; regeneration needs pixi sandbox init, which requires the conda-forge channel this sandbox cannot reach.
